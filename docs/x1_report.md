# X1: attack cards across four wallet configurations

The Phase-1 evidence: thirteen attack cards fired with the leaked agent key at four configurations holding the same funds. Generated by `tools/render_reports.py` from `results/x1_table.json` (the Foundry reader); every number carries its source marker.

## Protocol

- **R1** raw agent key: an EOA holding the funds, no policy (the floor).
- **R2** static allowlist and caps, what most teams build: target and selector allowlist, decoded per-transaction cap, calendar-day cap, static recipients, and an ERC-1271 that accepts the session key.
- **R3** ours without payee tiers: one-door ERC-1271, effect metering, all guards; every unknown payee needs owner approval (exploration off, no attestor).
- **R4** ours with payee tiers: R3 plus attested payee tiers and the account-wide exploration budget at its defaults.
- Every card replays the shared legit stream first (listed shops, an x402 payment through the one door, two attested payees, one cold payee), then attacks with the leaked key straight at the wallet. The freeze thresholds pinned on dev seeds apply to R3 and R4.
- **Two independent readers.** The Foundry cards (`contracts/test/cards`) and the TypeScript raw-key shooter (`agent/src/shooter`) fire the same deck from `agent/fixtures/deck_params.json`; `tools/x1_agree.py` compares them cell by cell.
- **Lost** = value that reached attacker-controlled addresses. **Beyond the bound** = lost minus the card's stated bound. USDC unless the card says ETH.
- Caveat: the deck and the legit stream are ours (self-graded); the payees and Sybils are synthetic. Both are in the repo so judges can add cards.

## Honest limits

- Self-graded: the deck, the legit stream and R2's exact configuration are ours.
- The raw-key column is one deterministic run per cell. That is the ground truth for a leaked key, not a rate.
- The x402 payment uses a local mock facilitator until the mainnet run (X3, user-run).
- On cards that drain a shared budget, legit payments can be blocked by design (liveness); those counts are reported as they are.
